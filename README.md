# 古月方源 · Guyue Fangyuan

> **一把抓住，顷刻炼化。**
> 丢进来任何东西，出去的是能直接用的零件。

一个给 AI Agent 用的**炼化技能**（Agent Skill / SKILL.md）：把任意材料——书、代码仓库、PDF、APP、网页、聊天记录、一套方法论——拆成**可执行的规则、可复用的结构、可验证的证据**，而不是一份摘要。

---

## 它解决什么问题

你可能有过这些时刻：

- 收藏了几十篇文章、几个教程视频、几本书，真正要用的时候一本都想不起来
- 想学一个开源项目的架构，读了两天源码，说不出它为什么这么设计
- 想把某个 App 的功能借鉴过来，最后只抄到一个长得像的壳
- 让 AI 总结一份材料，它给你一段废话，你还得自己回去读原文

**根本原因**：大多数"总结"是把长的说短，而你要的是**把外部的东西变成你能直接用的零件**。这两件事不一样。

古月的第 2 条铁律就是这个：

> **炼化不是总结。** 总结是把长的说短；炼化是把外部的东西变成你这里能直接用的零件：可执行的规则、可复用的结构、可验证的证据。**产出必须能被下一步直接吃掉。**

## 怎么用

### 三个典型场景

**① 把一本书 / 一套方法论变成可执行的东西**

```
用户：把这本书炼了，我要能直接用的方法
→ 读 TEXT.md。三步：拆（切最小可判断单元）→ 判（每单元一条带条件的主张）
  → 装（装配成规则集 / 检查表 / 决策树）
```

**② 拆一个 App，拿出它的机制**

```
用户：这个 APK 里的功能我要，怎么实现的
→ SOFTWARE.md 取证（结构 / 类 / 引用），再 TAKE.md 用五维提机制
→ 产出「机制规格书」：解决什么问题 / 结构 / 数据流 / 契约 / 决策规则 /
  边界与失败 / 我的最小等效实现 / 明确没拿到的
```

**③ 几个技能功能重叠，想合并**

```
用户：这几个技能干的事重复了
→ MERGE.md：先判"该不该合"（三个硬信号）→ 再判"按什么合"（三种模式）
  → 合完必须 replay 验证：看哪些任务翻转了，不看总分
```

### 一条最重要的使用原则

> **按需读取是铁律。** 只读本次任务落在的那一区手册。
> 发来一个 PDF 就不用管软件区；发来一个仓库就不用管文档区。
> 一次读全部不是勤奋，是烧上下文，还会把注意力稀释掉。

## 设计基线（十条铁律的摘要）

1. **先判构成，再选工具** —— 不按扩展名判，按"它是字、是图，还是机器码"判
2. **炼化不是总结** —— 产出必须能被下一步直接吃掉
3. **每条结论都要有落点** —— 文本落字符区间，文档落页，代码落文件+行，软件落地址/证据 ID
4. **观察 / 推断 / 未知三档分开**，不许混成一段
5. **不许假装读过** —— 缺工具就如实报缺口，并给降级路径
6. **一次只炼一块** —— 大东西先切，切完可并行；综合与定稿留在主代理
7. **产物分两堆** —— 能直接用的、待判的，不许混
8. **原料只读不改**
9. **新增前先查重** —— 现有文件有一节能装下就别新建；跨技能也查，别人做了就指向它
10. **不可逆操作先备份，然后只动备份**

完整版见 `SKILL.md`。

## 环境要求

**核心逻辑零依赖** —— 它是一堆 Markdown，纯文本，谁都能读。

`scripts/digest_batch.py` 只用 Python 标准库。以下是**选装**：

| 可选 | 用途 |
|---|---|
| Python 3.10+ | 跑批量脚本 |
| MarkItDown / MinerU | 文档转文本（见 `DOCUMENT.md`） |
| apktool + jadx + JDK 21 | Android 反编译（见 `TAKE.md` 附录） |
| REA（MCP server） | 二进制取证（见 `SOFTWARE.md`） |
| Ghidra / IDA | 原生代码反编译（可选；缺了走黑盒） |

> 文中出现的 `D:\tools\...`、`C:\Users\<user>\` 都是**示例路径，请换成你自己的**。

## 已知局限（诚实标注）

- **依赖外部工具的环节会失败**。没有反编译引擎就只能黑盒，没有 OCR 就提不了扫描件。技能的做法是**如实报缺口**，不是硬编一个结果。
- **`TAKE.md` 的「五维提取表」是归纳产物**，不是任何单一来源的原话，属于推断。用之前建议自己验证一次。
- **`DONTS.md` 的「狡辩对照表」来自一次实战实践**，不是论文结论——但它确实是对着 AI 的真实行为写的。
- **大量规则来自单机长期积累**（Windows + 中文路径 + 一堆踩过的坑）。换主机时，路径和工具相关的部分要重新核。
