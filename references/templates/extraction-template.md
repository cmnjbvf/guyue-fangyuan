# 批次笔记模板（每批一份，N 批共 N 份）

每个批次子代理把自己负责的那一批原文，按下面这个固定结构写成一份笔记。
**字段统一是融合质量的第一杠杆**：N 份笔记字段对齐，大笔记阶段才对得上。

```markdown
# 批次笔记 {batch_no}/{total}

- 覆盖范围：{本批主题/章节，一句话}
- 原文文件：{chunk 文件路径}

## 本批概要
{2-4 句话概括这一批讲了什么}

## 关键要点
- {要点，每条一行，重要的放前面}

## 流程 / 步骤
{本批出现的操作流程、实施步骤；没有就写"无"}

## 决策点 / 判断标准
{本批出现的选择依据、权衡标准、启发式规则；没有就写"无"}

## 踩坑 / 反模式 / 失败案例
{本批提到的错误做法、失败教训、注意事项；没有就写"无"}

## 值得原样保留的句子
{金句、定义、关键数据，必须原文照抄并标注大致位置}
- "……"（约第 X 段 / 章首）

## 专项提取（按本次任务指令填写）
{这里放任务定制字段。例如：
 - 人物设定：姓名/身份/动机/关系
 - 规则条款：条款号/生效条件/罚则
 - 数据指标：指标名/数值/口径
没有任务定制字段时，写"无"并删除本节示例}

## 跨批线索
{本批中出现"可能与别的批次有关联"的迹象：未完结的话题、指向其他章节的引用、
前后可能矛盾的说法、专有名词的首次出现。没有就写"无"}

## 存疑 / 没看懂
{本批中表述不清、明显缺上下文、或与常识不符的内容。没有就写"无"}
```

## 填写纪律（子代理必须遵守）

1. 只写自己读到的这一批原文里有的内容，**不许脑补**批次外的信息。
2. 任何字段找不到对应内容就写"无"，**不许留空、不许编造**。
3. "值得原样保留的句子"必须原文照抄，一个字符都不许改。
4. 每条要点尽量带位置线索（章/段），方便大笔记阶段溯源。
5. 拿不准是不是要点的，按"宁可多写进存疑区，不许混进要点区"处理。
