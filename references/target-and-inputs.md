# 输入、目标与领域适配

在目标路径、格式、领域或工具选择会影响处理时读取。

## 目标优先级

用户明确指定的输出目录/文件/知识库 > 当前已确认项目约定 > 对话内交付。相对路径按用户指明的项目根解释并报告解析后的绝对位置。来源目录不是默认输出目录。若同一路径同时充当来源，另建明确的成果子目录，排除其再次导入；不要覆盖原件。多目标仅写已指定对象，不因发现有用内容追加其他项目。

通用领域不套领域分类、10秒规则、工种和生产控制器。内容涉及视频不等于需要该领域入库。用户只要求蒸馏成方法，也不自动授权新建 Skill/SOP 或更改目标项目规则。事实知识、执行方法和风格提炼按实际目标分开；专门拆书或作者风格任务优先用已有 book-distill/author-style-distill 的合适流程，不强占它们的专门职责。

只有显式维护现有领域知识库时选 `domain-profile`；通用路线为 `generic`。这两个值是本工具的适配分支，不限制可处理领域或未来目标。

## 格式策略

| 来源 | 读取方式 | 必须保留的上下文与限制 |
|---|---|---|
| 粘贴文字、TXT、MD、日志 | 直接读授权正文 | 原始顺序、标题、说话人、版本、段落；编码错误不自动猜补 |
| JSON/JSONL、CSV/TSV | 按记录/字段或行解释 | 完整键名、表头、单位、空值语义和记录关联；辅助脚本只保存原样文本，不宣称完成结构解析 |
| HTML/网页 | 当前可用公共读取或适用浏览工具取得正文 | 标题、作者、日期、正文与评论的区别；登录和外发不扩大授权 |
| DOCX/PDF/PPT/XLSX | 使用当前可用文档能力；必要时比较 Docling/Unstructured 适配 | 页码/幻灯片/工作表/单元格、表头、脚注、图文关系；提取失败单列 |
| 图片、扫描件 | 可用视觉能力或已授权 OCR | 低清和多栏错序须复核；看不清不写成事实 |
| 音视频 | 已授权转录，必要时回看画面/图表 | 时间点、说话人、视觉证据；字幕不代替画面示范 |
| 压缩包、只有目录/链接的清单 | 先清点，按授权和工具能力取正文 | 不执行内含命令；未取得内容标 reference_stub/needs_extraction |

没有安装解析器也可以调用已有文档能力后导入提取文本；不能仅凭查到支持列表报告本机已支持。新解析器、模型下载、付费接口或外发按实际授权判断，不由本 Skill 自动触发。

原件、规范化正文和生成的上下文分开保存。规范化字符位置不是 PDF 页码；有原生 element_id/页码/时间戳时可在项目证据表另存映射。上下文解释只能消歧，不得作为原始引文。
