# 内置蒸馏器：开箱能用的那一套

> **什么时候读**：要把一个人 / 一位作者 / 一套本事，变成**能直接用的东西**时读。
> 只要原理和判据 → 读 `DISTILL.md`；要**现在就开跑** → 读本文件。

**这份文件是什么**：`DISTILL.md` 给的是骨架（六步），本文件给的是**填好的模板**——具体问什么、抽什么、怎么量化、产物长什么样、怎么验。

**它从哪来**：把外面五套成熟做法拆开，取各自最强的一段拼起来的。见文末落点表。

---

## 一、开跑前四个判断（不判清楚不开工）

### 判断 1 · 对象是哪一类

| 对象 | 判断依据 | 主要产物 |
|---|---|---|
| **一个人** | 有他的访谈/文章/演讲/决策记录 ≥5 份 | 思维模型包 |
| **一位作者** | 有他 3 本以上**已完结**作品 | 风格包 + 量化画像 |
| **一本书 / 一门课** | 有完整材料 + 想把它变成可执行方法 | 方法卡组 |
| **一套本事（技能/手艺）** | 有定义 + ≥3 次真实使用记录 | 技能卡 |
| **一个团队/组织** | 有他们的产出 + 决策记录 | 决策规则集 |

**判不出就停。** 对象类别错了，后面全错（比如把"一个人"当"一本书"蒸，会漏掉他的提问顺序）。

### 判断 2 · 素材够不够（硬门槛，不够就停）

| 对象 | **最低**样本 | 为什么不能再少 |
|---|---|---|
| 一个人 | **≥2 份不同场景**的访谈/文章 | 单份无法区分"他的方法"和"这次的处理"【开源 skill `distill-persona` 的硬要求】 |
| 一位作者 | **≥3 本**（跨题材更好） | 一本可能是特例，三本才看得出稳定模式 |
| 一本书 | 完整原文 + **≥2 篇**外部解读/批评 | 只看原文会漏掉它被误用的地方 |
| 一套本事 | 完整定义 + **≥3 次**真实使用记录 | 光看定义看不出什么情况下失灵 |

**样本同质等于没取样。** 同一个访谈里说十遍的，还是那一件事。

### 判断 3 · 要哪一档（先谈成本，别开跑了才发现收不住）

| 档 | 素材量 | 产出 | 大致耗时 |
|---|---|---|---|
| **快速** | 每维度 3–5 个来源 | 能用的骨架 + 3 条核心判据 | 半小时级 |
| **标准**（默认） | 6 个维度完整覆盖 | 完整思维模型包 / 风格包 | 数小时 |
| **深度** | 一手素材全量 + 量化 + 回放验证 | 可开源发布的成品 | 一天级 |

**默认走"标准"**，除非用户说要快或要精。

### 判断 4 · 要什么产物

| 用途 | 产物形态 | 判据 |
|---|---|---|
| 当顾问（"他会怎么看"） | 思维模型包 | 能扮演他回答新问题，且说出"他会先问什么" |
| 当规则（"按他的标准检查"） | 检查清单 | 每条都是可打勾的具体动作 |
| 当风格（"写得像他"） | 风格包 + 量化画像 | 盲测能区分|
| 当方法（"按他的流程做"） | 流程卡 | 别人不看原文能照着走完 |

## 二、六层结构（从"怎么写"到"怎么想"到"怎么呈现"）

原来流行的做法分四层（事实/模式/决策/人格）。把它扩成六层，因为**四层混掉了"写什么"和"怎么写"**，实测下来会漏 L3（选题）和 L4（素材），而那两层恰恰是"像但不会用"的主因。

| 层 | 抽什么 | 具体维度（照这个清单抽） | 缺了会怎样 |
|---|---|---|---|
| **L1 语言层** | 怎么说话 | 句长分布 / 长短句比例 / 单句成段频率 / 对话占比与标记（引号开头？后接动作？"他说"频率）/ 标点习惯 / 用词层（口语·梗·术语·禁用词）/ **情绪表达方式（直写心理 vs 动作暗示）** / 口癖与高频句式（**跨材料出现才算**）/ 比喻的喻体来源域 / 幽默机制（讽刺·自嘲·荒诞·反差） | 像，但是死的 |
| **L2 结构层** | 怎么搭 | 骨架公式 / 字数与段落模型 / 开头开法分布 / **结尾收束类型分布**（悬念·反转·金句·行动）/ 信息释放顺序（先果后因？）/ 冲突升级节奏（每多少字推进一次）/ POV 规则与切换 / 反转手法偏好（信息差·时间闭环·身份揭露）/ 伏笔埋设与回收习惯 | 换个题目就散架 |
| **L3 选题层** ⭐ | 选什么 | 发布时机 / 切入角度 / 话题优先级 → 产出**选题判断树** | 会写不会选，产能上不去 |
| **L4 素材层** ⭐ | 用什么料 | 引用来源类型 / 权威对象选取标准 / 数据使用方式 → 产出**素材偏好清单** | 内容空，全靠观点撑 |
| **L5 认知层** ⭐ | 怎么想 | 对核心概念的理解 / **决策启发式（必须写成规则）** / 反复出现的母题与假设 | **没有灵魂** |
| **L6 呈现层** | 怎么摆 | 配图策略 / 排版格式 / 层级与留白 | 只有文字，没有整体感 |

> **原则**：**L1–L2 是"怎么写"，L3–L5 是"怎么想"，L6 是"怎么呈现"。三样齐了才算复刻，缺一样就是模仿秀。**

### 跨层铁律：图片必须打开看

**很多材料里的图不是装饰**——截图、对话记录、数据表格、评论截图，是论证链的一部分。**只看文字会漏掉精确数据（它常常只存在于图里）。**

**执行要求**：抽样 5–10 份材料，逐张打开图片，评估它携带的实质信息比例。分类：证据型 / 演示型 / 数据型 / 叙事推进型 / 情绪型。

## 二之二、两个执行加速器

### ① 并行提取（一次任务拆给几个子代理）

```
主代理：先把材料分级、定统一术语表
   ↓
脚本层：L1 语言层 → 直接跑 `style_metrics.py`（不用模型判断）
子代理：L2 结构 / L3 选题 / L4 素材 / L5 认知 → 各派 1 个，并行提取
   ↓
主代理收口：去重、裁决冲突、写进同一份规格书
```

**为什么 L1 单独走脚本**：句长、标点密度这类是可复算的，模型估不准还费 token。

**为什么收口必须在主代理**：5 个代理各自去重，合并时同一件事会有 5 个版本且互相矛盾（见 `PLAYBOOK.md`）。

### ② 两道晋级门（防止把"素材"当"结论"）

每个提取出来的单元，要过两道门才能进产物：

| 门 | 问什么 | 不过怎么办 |
|---|---|---|
| **知识门** | 有原文逐字支撑吗？是一次性说法还是反复出现？ | 一次性说法 → 降级成"素材"，不进规则 |
| **产品门** | 能独立使用吗？有明确触发条件吗？ | 没有触发条件 → 降级成"描述" |

**两门都过才算 promoted。** 这道门的作用：把"他说过一句话"和"他反复这样判断"分开——**后者才是可用的规则**。

## 二之三、压力测试回炉（做完不等于做对）

产物写完后，拿 **3–5 个真实发生过的问题**去测：

| 现象 | 说明 | 动作 |
|---|---|---|
| 答不上 | 那一维没抽到 | 回材料补抽 |
| 答得像通用常识 | 抽到的是现象层，不是他的判断 | 回 L5 重做 |
| 答得对但说不出为什么 | 只有结论没有依据 | 补"落点"（原文位置） |

**没经过这一步的蒸馏，只是"我觉得像"。**

## 三、七类抽取维度（含三个负面维度）

| # | 维度 | 问什么 | 来源 |
|---|---|---|---|
| 1 | 提问顺序 | 遇到新问题，**先问什么、后问什么** | 各家通用 |
| 2 | 判断标准 | 他评价事物用的词和依据（"这个好，因为…"） | 各家通用 |
| 3 | **审美犯罪** ⭐ | **什么让他对别人的东西感到不适** | Hassid 100 问 |
| 4 | **绝对禁区** ⭐ | **他永远不会做/写/说的是什么** | Hassid 100 问 |
| 5 | **红旗信号** ⭐ | **什么让他立刻不信任一段内容/一个方案** | Hassid 100 问 |
| 6 | 语言指纹 | 句长、标点习惯、比喻来源域、口癖 | 量化工具 |
| 7 | 边界 | 他的方法**在什么情况下失效**、他自己承认过什么局限 | 各家通用 |

### 为什么三个负面维度值钱

正面问题（"你喜欢什么"）得到的是**他希望你看到的**；负面问题得到的是**他的真实判据**。

> 问"你欣赏什么风格" → 他会说"简洁有力"（正确但无用）
> 问"什么让你立刻不信任一段文字" → 他会说"开头三行没给出新信息我就关掉"（立刻可用）

**三个负面维度是这份文件相对其他配方的主要增量。**

## 四、语言层量化（能跑脚本就别靠感觉）

风格判断最不可靠的就是"我觉得像"。能变成数字的先变成数字。

```bash
python scripts/style_metrics.py <文件或目录>
python scripts/style_metrics.py 新稿.md --compare 原作者.md
```

**输出什么**（节选）：

| 组 | 指标 |
|---|---|
| 句长 | 平均 / 中位 / 最短 / 最长 / 标准差 / 四区间分布 / 短句比例 |
| 句型 | 问句占比 / 感叹句占比 |
| 标点密度 | 每百字的 ，。！？；：、（）—… 密度 |
| 人称 | 第一/第二/第三人称每百字用量 |
| 词汇 | 2-gram 多样性 |
| 段落 | 平均段落长度 / **单句段落比例** |
| 语气 | 模糊限制语总数、每千字频次、明细 |

**怎么用**：
1. 先跑**原作者 3 份以上**，得到基线区间
2. 再跑**你的稿子**，`--compare` 直接看差异
3. **只看两三个差异最大的指标**，不要全都追——全套对齐会写出没有人味的文字

**关键判据**：句长标准差偏小 = 节奏平（该长该短没有变化）；单句段落比例高 = 会断句停顿；模糊语每千字偏高 = 立场软。

## 五、决策原则怎么写（L5 认知层的具体做法）

### 公式

```
当 <什么情境> 时，先检查 <哪一个具体事实>，
若 <不满足什么条件>，则 <做什么动作>。
```

### 对照

| ❌ 鸡汤版 | ✅ 可执行版 |
|---|---|
| "要系统思考" | "接手任何需求，先问：这件事如果做成了，用户会在哪个场景用到？说不出场景就先别做" |
| "重视用户体验" | "看到任何界面改动，先数用户从进入到完成要点几次；超过 5 次就砍步骤" |
| "保持长期主义" | "遇到要不要接的活，先问：这件事三年后还在给我产生收益吗？不能就推掉" |

### 三条自检

- [ ] 每条都能被第三个人**照着做**，不用再问"具体怎么做"？
- [ ] 每条都带**触发条件**（"当…时"），不是任何时候都成立？
- [ ] 每条都有**反向动作**（不满足时怎么办），不是只说"要注意"？

**5–7 条就够。** 超过 10 条，用户记不住，等于没有。

## 六、验证：三条硬标准

| # | 标准 | 怎么测 | 不过怎么办 |
|---|---|---|---|
| 1 | **不编造** | 每条引语/事例都能**逐字回到原文** | 回不到的全部删掉或标"推断"【`distill-persona` 的硬规矩】 |
| 2 | **盲测能区分** | 拿一份没参与蒸馏的新材料，让你和原作者（或原书）各自处理，让别人猜哪个是谁的 | 猜不出 → 只蒸到现象层，回第 ③ 层重做 |
| 3 | **回放能对上** | 拿 3–5 个历史上真实发生过的问题，看产物给出的判断是否与原主一致 | 对不上 → 检查是不是把"他的做法"写成了"你认为他应该的做法" |

**三条里 1 是底线，2 和 3 至少过一条。**

## 八、和外部那些配方怎么配合

| 情况 | 用什么 |
|---|---|
| 对象是**一个人**，要精品 | `nuwa-skill`（女娲，流程最细，带成本档位和候选推荐） |
| 对象是**一位作者**，要能续写 | `author-style-distill` + 本文件的**语言量化**补强 |
| 对象是**一本书**，要拆成方法 | `book-distill` |
| 对象**跨类**，或要一个**能同时干几样**的 | **本文件**（四层 + 七维 + 三模板） |
| 只要**数字**，不要判断 | `scripts/style_metrics.py` 单独跑 |

**本文件的定位**：不是替代它们，是**它们的公共底层 + 缺失补丁**（尤其三个负面维度和量化脚本）。

### 一个原属 `book-distill` 的能力：换皮改写

蒸完一本书之后，还有一步常用操作——**保留结构骨架，换掉题材与世界观**。

做法：L2 结构层（骨架公式/节奏/钩子类型）原样保留，L1 语言层重写，L3–L5 按新题材重建。
**判据**：写完自问"这骨架换个性别/换套设定还成立吗？"成立 → 你拿到的是结构；不成立 → 你只是抄了情节。
